# Três imagens para testar Vision

Após iniciar o Acolhe, abra **Para educadores → Objetos que ensinam**, selecione uma foto desta pasta e clique em **Reconhecer objetos**. Estas imagens acompanham o clone; não é necessário montar o dataset nem treinar o modelo.

As três fotografias foram copiadas sem alteração dos bytes revisados. `credits.json` registra a fonte, autoria, licença e SHA-256 de cada uma. Preserve estes créditos ao reutilizá-las; os autores não endossam o projeto.

São exemplos de demonstração já examinados, não um teste independente. A confiança mostrada por objeto não é a precisão global do modelo. A pasta não contém fotografias de usuários do Acolhe. O detector não identifica rostos nem decide travessias.
