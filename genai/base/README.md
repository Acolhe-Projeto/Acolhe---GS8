# Base atribuída

Fonte canônica de runtime: ../data/corpus.json. corpus.json é snapshot v3 de entrega com hash registrado em manifest.json; fontes.csv lista atribuição/licença por microlição. São oito documentos bilíngues (16 campos de idioma), não 16 fontes independentes. Revisão pedagógica pendente. Mudanças futuras exigem atualizar snapshot, manifesto e avaliação em conjunto.

O corpus v3 inclui visões monolíngues dos mesmos fatos para evitar tradução indevida em perguntas de orientação. Avaliação e limitações atuais: docs/entregas/RESULTADOS_NOTURNOS.md.
